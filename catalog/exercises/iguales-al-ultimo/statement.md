# [a4035] Iguals a l'últim #arrays

Donada una seqüència de nombres, dir quants nombres de la seqüència són iguals a l'últim (sense comptar-se ell mateix).

## Input Format

El primer nombre  indica la quantitat de nombres que hi ha a la seqüència. A continuació ve la seqüència.

## Constraints

-

## Output Format

La quantitat de nombres iguals a l'últim.

## Sample Input 0

```text
5
23 34 23 45 23
```

## Sample Output 0

```text
2
```

## Sample Input 1

```text
1
23
```

## Sample Output 1

```text
0
```

## Sample Input 2

```text
5
12 23 34 45 56
```

## Sample Output 2

```text
0
```

## Sample Input 3

```text
3
100 100 100
```

## Sample Output 3

```text
2
```

## Sample Input 4

```text
2
23 23
```

## Sample Output 4

```text
1
```
