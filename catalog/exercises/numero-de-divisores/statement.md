# Número de divisores

Dado un número, calcula la cantidad de divisores que tiene.

## Input Format

Un número entero N

## Constraints

0 <= N <= 10^9

## Output Format

Un número indicando la cantidad de divisores

## Sample Input 0

```text
6
```

## Sample Output 0

```text
4
```

## Explanation 0

El 6 es divisible por 1, 2, 3 y 6

## Sample Input 1
