# Llibres i prestatgeries

Per a endreçar els seus llibres, Miquel ha comprat unes prestatgeries.
Cada prestatgeria té un nombre de prestatges, i a cada prestatge hi caben una quantitat de llibres determinada.
En Miquel vol saber si ha comprat suficients prestatges.

## Input

El primer nombre  indica la quanitat de prestatgeries.

El segon nombre  indica el nombre de prestatges que té cada prestatgeria.

El tercer nombre  indica el nombre de llibres que hi caben a cada prestatgeria.

L'últim nombre  indica la quantitat de llibres que té en Miquel.

## Output

`true` | `false`
