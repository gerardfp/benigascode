# Cuenta palabras

Dado un texto, cuenta el número de palabras que contiene.

## Input Format

Un string con varios saltos de línea.
El texto termina con la palabra END (que no debe procesarse)

## Constraints

1 <= L <= 100

## Output Format

Un entero indicando el número de palabras

## Sample Input 0

```text
hola mundo!
END
```

## Sample Output 0

```text
2
```

## Sample Input 1

```text
hola, que tal.
END
```

## Sample Output 1

```text
3
```

## Sample Input 2

```text
Lorem ipsum dolor sit amet,
consectetur adipiscing elit.
END
```

## Sample Output 2

```text
8
```

## Sample Input 3

```text
Lorem ipsum
dolor sit amet,
consectetur adipiscing
elit.
END
```

## Sample Output 3

```text
8
```
