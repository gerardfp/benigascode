# [C7-L2-2] Reverse String #recursivitat

Donat un String, invirteix-lo.

## Input Format

Una línia de text

## Constraints

No hi ha.

## Output Format

El text amb l'ordre dels caracters invertit.

## Sample Input 0

```text
abcde
```

## Sample Output 0

```text
edcba
```

## Sample Input 1

```text
ab c d efgh
```

## Sample Output 1

```text
hgfe d c ba
```

## Sample Input 2

```text
cgctagcttagctaacg
```

## Sample Output 2

```text
gcaatcgattcgatcgc
```
