# Cuenta números

Se deben ir leyendo números hasta que se lea un 0. El programa debe mostrar la cantidad de números leídos antes del 0.

## Input Format

Una secuencia de N números.

## Constraints

0 <= 1 <= 10^7

## Output Format

Un entero indicando la cantidad de números leídos

## Sample Input 0

```text
0
```

## Sample Output 0

```text
0
```

## Sample Input 1

```text
5 4 2 5 7 0
```

## Sample Output 1

```text
5
```

## Sample Input 2

```text
3 5 6 3 0
```

## Sample Output 2

```text
4
```

## Sample Input 3

```text
8 6 -1 7 0
```

## Sample Output 3

```text
4
```

## Sample Input 4

```text
7 4 6 9 0
```

## Sample Output 4

```text
4
```

## Sample Input 5

```text
5 8 0
```

## Sample Output 5

```text
2
```
