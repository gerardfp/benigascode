# Elimina vocales

Dada una frase (terminada con un salto de linea), escribe la misma frase pero eliminando las vocales.

## Input Format

Una frase terminada con un salto de linea '\n'

## Constraints

1 <= L <= 100

## Output Format

La frase sin las vocales.

## Sample Input 0

```text
hola mundo!
```

## Sample Output 0

```text
hl mnd!
```

## Sample Input 1

```text
lalalA
```

## Sample Output 1

```text
lll
```

## Sample Input 2

```text
xa, XA, xE, xI, xO, xu
```

## Sample Output 2

```text
x, X, x, x, x, x
```

## Sample Input 3

```text
xAaAxeEe
```

## Sample Output 3

```text
xx
```
